# 📄 1. Resumo do Sistema

**Intenção:** alinhar visão geral (o que é e por que existe)
**Como preencher:**

* problema → solução → público → diferencial → monetização
  **Resumo:** é o “pitch técnico + negócio”

---

# 👥 2. Usuários (Personas)

**Intenção:** definir quem usa e como se comporta
**Como preencher:**

* tipo de usuário → objetivo → comportamento → nível de uso
  **Resumo:** define para quem o sistema é feito

---

# 🧩 3. User Stories

**Intenção:** definir o que o sistema precisa fazer
**Como preencher:**

* “Como [usuário], quero [ação], para [resultado]”
  **Resumo:** vira backlog funcional

---

# 🗺️ 4. Roadmap

**Intenção:** organizar a execução por fases
**Como preencher:**

* dividir em fases (MVP → inteligência → monetização → escala)
  **Resumo:** define quando cada coisa será feita

---

# 🏗️ 5. Arquitetura

**Intenção:** definir como o sistema funciona tecnicamente
**Como preencher:**

* frontend → backend → banco → IA → integrações
  **Resumo:** visão estrutural do sistema

---

# 🧬 6. Modelo de Dados

**Intenção:** estruturar as informações do sistema
**Como preencher:**

* entidades → relações → eventos
  **Resumo:** define o banco e a base lógica

---

# ⚙️ 7. Fluxos

**Intenção:** definir o comportamento do sistema
**Como preencher:**

* ações → eventos → respostas do sistema
  **Resumo:** mostra como tudo acontece na prática

---

# 📊 8. Métricas (KPIs)

**Intenção:** medir sucesso
**Como preencher:**

* engajamento → conversão → retenção
  **Resumo:** valida se o sistema funciona

---

# 🚀 9. Go-To-Market

**Intenção:** definir como lançar e crescer
**Como preencher:**

* público inicial → estratégia → canais → aquisição
  **Resumo:** leva o sistema pro mundo real

---
