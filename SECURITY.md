# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please report it privately.

- Email: `security@zapzou.com.br`

Please include:
- A detailed description of the issue
- Steps to reproduce (proof-of-concept if possible)
- Impact assessment and affected areas (routes, tables, policies)

## Scope

This project includes client code (Next.js) and database rules (Supabase/PostgreSQL RLS, triggers and functions under `migrations/`).
